## Projects

**[MovieMind](https://github.com/Sanskar1314/Movie_Recommendation_End_to_End)** — Content-based movie recommender built on 45,000+ titles using TF-IDF + cosine similarity, served through a FastAPI backend with a Streamlit UI. Includes fuzzy title matching and live poster fetching via the TMDB API.

**[RAG-Based AI Teaching Assistant](https://github.com/Sanskar1314/RAG_Based_Teaching_Assistant)** — Turns lecture video audio into a searchable knowledge base: Whisper for transcription, BGE-M3 embeddings via Ollama, FAISS for retrieval, and Gemini for grounded answers. Flask backend, Streamlit frontend, Dockerized.
